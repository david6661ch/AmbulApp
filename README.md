Ambul-app

Descripción del problema: Servicio complementario para personas con movilidad reducida, condiciones médicas específicas que requieran hacer desplazamientos a diferentes centros médicos de diferentes localidades del Valle de Aburrá. 

Historias de usuarios
Tres páginas, una de inicio, una para el formulario y otra para los servicios particulares.
una opción de log-in en la página de inicio. 
Una página solo para el log-in.
Un formulario sign-up. 
En la página de inicio debe haber una descripción específica del servicio. 
en una página aparte, una sección tipo dashboard que muestre su historial de solicitudes de servicio. 
En la página del formulario debe mostrar la disponibilidad del servicio. 
en la página de servicios particulares, una tabla de precios por kilómetro y por tipo de servicio.
